# تحديث التطبيق مع الحفاظ على البيانات المحلية

1. أوقف الواجهة وأي تشغيل آلي، ثم خذ نسخة احتياطية كاملة من مجلد التطبيق القديم.
2. فكّ النسخة الجديدة في مجلد منفصل وثبّت متطلباتها عبر `setup.bat` على Windows أو `./setup.sh` على Linux.
3. انقل إلى المجلد الجديد ملفات الإعداد والبيانات التي تحتاجها فقط، مثل `config.ini`، و`client_secrets.json`، وملفات `*_token.json`، و`cookies.txt`، وقوائم الصفحات والحسابات وسجل الحقوق وحالة الرفع.
4. لا تنقل ملفات البرنامج القديمة أو مجلدات التخزين المؤقت. افتح الواجهة الجديدة وتأكد من الإعدادات، ثم شغّل `./run_automation.sh --preflight` على Linux أو `run_automation.bat --preflight` على Windows قبل تفعيل التشغيل الآلي.
5. احتفظ بالنسخة الاحتياطية حتى تتأكد من ظهور الحسابات والإعدادات والسجل المطلوب في النسخة الجديدة.

كل الملفات المذكورة في الخطوة 3 بيانات محلية حساسة: لا ترفعها إلى GitHub ولا ترسلها في أرشيف عام. يظل `config.ini.example` قالباً عاماً؛ لا تستبدله بملف الإعداد الحقيقي عند النشر.
